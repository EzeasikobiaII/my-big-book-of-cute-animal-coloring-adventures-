### Standard Header and Lettering Rules

Every animal coloring page must use this exact header:

COLOR • IMAGINE • HAVE FUN!

- Every header letter must have a bold black outline.
- Every header letter must have a white, unshaded interior.
- Children must be able to colour inside every letter.
- Never use solid-black or grey-filled header lettering.
- Keep the header style, size, and placement consistent across all 50 animal pages.
- Paw-print decorations may remain solid black.

Every animal name must appear below its illustration in large, bold outlined letters with white, unshaded interiors.

Never fill an animal name with solid black.

Both the header and animal name must be colourable.
