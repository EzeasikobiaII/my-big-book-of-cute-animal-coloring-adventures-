# KDP Paperback Production Checklist

## Book
- [ ] Title matches cover and KDP metadata
- [ ] Subtitle matches cover and KDP metadata
- [ ] Author name matches all files
- [ ] Final page count confirmed

## Interior
- [ ] 8.5 × 11 inch trim size
- [ ] No bleed
- [ ] Black-and-white interior
- [ ] Individual pages, not spreads
- [ ] 300 DPI artwork
- [ ] Images embedded
- [ ] Fonts embedded
- [ ] No crop or trim marks
- [ ] No comments or annotations
- [ ] No placeholder text
- [ ] No copyrighted characters or logos
- [ ] Margins checked
- [ ] Pages in correct order
- [ ] Final PDF checked

## Cover
- [ ] KDP cover template generated
- [ ] Front cover matches metadata
- [ ] Back cover checked
- [ ] Spine calculated from final page count
- [ ] Barcode area respected
- [ ] Cover PDF checked

## KDP
- [ ] AI-generated content disclosure completed if applicable
- [ ] Description checked
- [ ] Keywords checked
- [ ] Categories checked
- [ ] Print Previewer passed
- [ ] Proof copy reviewed
- [ ] Final files uploaded
- [ ] Final listing reviewed
